Minangka syair sastra utawa kidung donga, panulisan asline pancen kudu nggunakake kosakata sing dhuwur drajate, sugih basa (kaya akan bahasa), lan ngebaki unggah-ungguh (sopan sanget) marang Gusti. Jenenge wae dhasaran utawa pondhasi sastra, dadi pancen kudu digawe sekokoh lan seendah mungkin dhisik.
